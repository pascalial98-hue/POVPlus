# Calibration artwork / 校准插图

`src/PovPlus/Assets/calibration-heads.png` is an instructional redraw made with the built-in image generation tool, using the official FFXIV Hyur Midlander player character as reference. It is not an official Square Enix illustration or an in-game screenshot. FFXIV character designs belong to SQUARE ENIX. This independent plugin is not endorsed by Square Enix.

校准图通过内置图像生成工具，参考 FF14 官方中原之民玩家角色重绘，用于说明视点位置；不是官方发布的插图或游戏截图。FF14 角色设计归 SQUARE ENIX 所有，本插件由社区独立维护。

The artwork is embedded in the plugin, with no network download during use. Labels and nose-bridge target markers are drawn separately for Chinese/English localization. Native character proportions vary; users should align the actual live marker to their own model.

插图嵌入插件，使用时无需联网。中英文字与鼻梁标记由界面单独绘制。种族和角色脸型不同，应以自己角色上的实时标记为准。

## Final generation prompt / 最终生成提示词

Use case: scientific-educational.
Asset: a polished FINAL FANTASY XIV player-character head atlas for an in-game first-person viewpoint calibration guide.
Reference images 1 and 2 are official FFXIV Hyur Midlander promotional screenshots. Use the short dark-haired male Midlander PLAYER CHARACTER in these references as the character identity. These references are identity/style references, not an image to preserve as a screenshot. Preserve his recognizable in-game face shape, short dark spiky hairstyle, dark eyebrows, pointed sideburns, clean-shaven face, and the white-and-brown starter-outfit collar. Match the FFXIV game-render aesthetic with clean stylized surfaces and convincing game-character anatomy. NOT a real-life human portrait, NOT a generic AI fashion model, no cinematic photoreal skin pores.
Create ONE wide 2:1 image, on uniform dark slate #222730, with two same-scale matching head-and-short-neck views. LEFT HALF: exact straight-on front view with neutral face and eyes looking level. RIGHT HALF: exact right-facing 90-degree side profile of the SAME male player character. Entire hair, ears, chin and short neck visible in both, comfortable margins. Eye line around 44% image height. Left head centered at 25% image width. Right head centered at 75%, with nose fully inside the right boundary. Crop outfit only at upper collar; the faces dominate.
Polish: high-quality crisp game promotional character render, soft even studio lighting, detailed but restrained hair strands, clearly visible eyelids, clear nose bridge/root between eye corners, distinct side-view bridge at EYE LEVEL and nose tip below/further forward. Nose/eyes must be unobscured. Accurate enough for instructional overlay. Neither overly realistic nor crude angular line drawing.
Absolutely no UI, lettering, logos, text, symbols, crosshairs, target markers, arrows, borders, separate panels or landscape. Only the two matched FFXIV heads on the flat dark-slate background. Output finished production artwork.
